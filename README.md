
# Multi-Brand Marketing Campaign Performance Analysis and Prediction

## Project Overview

This project analyses marketing campaign performance across three beauty brands: Nykaa, Purplle, and Tira.

The project uses Python for data cleaning, preprocessing, exploratory data analysis (EDA), and machine learning.

Two machine learning models are developed:
- Linear Regression to predict campaign revenue.
- Logistic Regression to predict campaign profitability.

A Streamlit application allows users to enter campaign metrics and view predicted revenue and profitability.

## Project Objectives

- Clean and preprocess marketing campaign datasets.
- Analyse campaign performance across three brands.
- Compare marketing channels and ROI.
- Identify relationships between campaign metrics.
- Predict campaign revenue using machine learning.
- Classify campaigns as profitable or non-profitable.
- Build an interactive Streamlit prediction application.


## Dataset Description

This project uses marketing campaign datasets from three beauty brands:

1. Nykaa - nykaa_campaign_data_with_nulls.csv
2. Purplle - purplle_campaign_data_with_nulls.csv
3. Tira - tira_campaign_data_with_nulls.csv

The three datasets were combined for multi-brand analysis.

### Important Dataset Columns

- Campaign_ID: Unique identifier for each campaign.
- Campaign_Type: Type of marketing campaign.
- Target_Audience: Intended audience for the campaign.
- Duration: Duration of the campaign.
- Channel_Used: Marketing channels used.
- Impressions: Number of times advertisements were displayed.
- Clicks: Number of advertisement clicks.
- Leads: Potential customers generated.
- Conversions: Successful customer conversions.
- Revenue: Revenue generated by the campaign.
- Acquisition_Cost: Recorded campaign acquisition cost.
- ROI: Return on Investment.
- Engagement_Score: Customer engagement measurement.
- Customer_Segment: Customer category.
- Date: Campaign date.


## Data Cleaning and Preprocessing

The following steps were performed using Python and Pandas:

1. Loaded three marketing campaign datasets.
2. Examined dataset shapes, columns, and data types.
3. Combined the datasets into one DataFrame.
4. Identified missing values and checked duplicate records.
5. Filled missing Campaign_ID values with unique identifiers.
6. Handled missing values in numerical and categorical columns.
7. Retained missing Date values as NaT.
8. Applied MultiLabelBinarizer to encode marketing channels.
9. Created Profit_Flag based on ROI values.
10. Validated ROI calculations and identified inconsistencies.

### Data Preprocessing Results

- Combined dataset: 166,635 rows.
- Encoded six marketing channels.
- Created a binary profitability classification target.
- Prepared the dataset for machine learning models.


## Exploratory Data Analysis (EDA)

Exploratory Data Analysis was performed using Pandas,
Matplotlib, and Seaborn.

### Analyses Performed

1. Compared marketing campaign performance across
   Nykaa, Purplle, and Tira.
2. Analysed average revenue and ROI by marketing channel.
3. Identified the highest and lowest ROI campaigns.
4. Examined relationships between campaign metrics
   using correlation analysis.
5. Visualised the relationships using a correlation heatmap.

### Key Observations

- Revenue and Conversions showed a strong positive
  correlation (0.88).
- Revenue and ROI showed a positive correlation (0.78).
- Clicks and Conversions showed a positive correlation (0.81).
- Acquisition Cost and Revenue showed a negative
  correlation (-0.40).
- Average ROI was similar across the six marketing
  channels, ranging approximately from 2.67 to 2.73.


## Machine Learning Models

Two machine learning models were developed using Scikit-learn.

### 1. Revenue Prediction — Linear Regression

Linear Regression was used to predict marketing campaign revenue.

The dataset was divided into:
- 80% training data
- 20% testing data

**Evaluation Results:**
- MAE: 148,535.29
- RMSE: 229,553.16
- R² Score: 0.7768

The model achieved an R² score of approximately 0.78,
explaining about 77.68% of the variation in test revenue.

### 2. Profitability Prediction — Logistic Regression

Logistic Regression was used to classify campaigns
as profitable or non-profitable.

StandardScaler was applied through a machine learning
pipeline before Logistic Regression.

**Evaluation Results:**
- Accuracy: 90.39%
- Precision: 91.94%
- Recall: 95.76%
- F1 Score: 93.81%

These metrics describe performance for the profitable
class, except accuracy, which measures overall correctness.

### Model Features

Both models used seven numerical features:

- Impressions
- Clicks
- Leads
- Conversions
- Acquisition_Cost
- Engagement_Score
- Duration


## Streamlit Application

An interactive web application was developed using
Streamlit to predict marketing campaign performance.

### Application Features

- Enter campaign details using sidebar input fields.
- View the campaign input summary.
- Predict campaign revenue using Linear Regression.
- Predict campaign profitability using Logistic Regression.
- Display the estimated probability of profitability.

### Input Features

1. Impressions
2. Clicks
3. Leads
4. Conversions
5. Acquisition Cost
6. Engagement Score
7. Duration

### Prediction Results

The application displays:

- Predicted Revenue
- Predicted Status (Profitable or Non-Profitable)
- Estimated Probability of Profitability

### Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib

### Running the Application

Open the project folder in VS Code.

Run the following command in the terminal:

```bash
streamlit run app.py
```

The application opens in a web browser.

**Note:** Predictions are estimates based on historical
campaign data and should not be treated as guaranteed
financial outcomes.

## Key Business Insights

- Nykaa generated slightly higher total revenue than Purplle and Tira.
- Instagram recorded the highest average revenue among the marketing channels.
- Email recorded the highest average ROI.
- Conversions showed a strong positive correlation with revenue.
- Channel performance differences were relatively small.

## Project Limitations

- The original ROI values contain some inconsistencies.
- The models have not yet achieved the project's 95% performance targets.
- Linear Regression can produce negative revenue predictions.
- Profitability predictions may conflict with revenue predictions.
- The current Streamlit application uses seven numerical inputs and does not yet include channel selection.

## Conclusion

This project demonstrates an end-to-end marketing analytics
workflow using Python, Pandas, Scikit-learn and Streamlit.

The analysis provides insights into campaign revenue,
marketing channel performance and profitability.

Two baseline machine learning models were developed
and integrated into an interactive prediction application.

Future improvements include model tuning, additional
algorithms, categorical feature integration and improved
prediction consistency.
